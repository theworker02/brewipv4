# brewipv4

Brew color ipv4 values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/brewipv4/

## Install / run

```bash
git clone https://github.com/theworker02/brewipv4.git
cd brewipv4
node src/cli.js
node --test
```
